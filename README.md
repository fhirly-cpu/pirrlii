# Tugas RPL Creative

## Tujuan Tugas
Tugas ini dibuat untuk belajar menggunakan GitHub dan memahami cara membuat serta mengelola repository. Selain itu, tugas ini juga untuk melatih kerja sama dan kreativitas dalam membuat project RPL.

## Cara Pakai
1. Buka repository GitHub.
2. Pilih file yang mau dilihat atau diedit.
3. Lakukan perubahan sesuai kebutuhan.
4. Simpan perubahan dengan klik **Commit changes**.
5. Cek kembali hasilnya di repository.

## Catatan
Repository ini dibuat untuk tugas sekolah kelas XI RPL.
